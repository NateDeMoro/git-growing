## Files

  - `Scene3D.tsx`: the dynamic-import wrapper with server rendering off. It replaces the Phase 0 placeholder and keeps the same props.
  - `SceneMap.tsx`: react-map-gl/maplibre map with a deck.gl MapboxOverlay in interleaved mode.

  - `useAnimationLoop.ts`: one loop for particles and easing.
  - `camera.ts`: fly-in, focus, presets and the toggle.
- `src/lib/scene/`: pure helpers, no React, no deck imports.
  - `geometry.ts`: feet to scene elevation with the single 10x factor, and metres to degrees near the site
  - `wind.ts`: speed and direction to a velocity
  - `lid.ts`: lid height for a frame
  - `drift.ts`: drift behavior (ceiling, sideways spread, rise rate, downwind reach) from a frame and an assessment
  - `trees.ts`: tree grid inside a polygon along its bearing, with the cap
  - `advect.ts`: one advection step with wrap-around inside a box
  - `ease.ts`: easing between two frames' layers
- `scripts/fetch-neighbors.ts` and `data/neighbors.geojson`: Overpass within 3 km, the main server and then one mirror. If both fail, write a hand-placed fallback (a house cluster, a school, a county road) with `illustrative: true`.
- `tests/scene.test.ts`.

## Contract fields used (src/lib/contract.ts; conform, never rename)
Read contract.ts on main before writing anything that touches frames. Use its real names. The plan describes these fields:
- SceneFrame:
  - time, plus the layers list (height ft, temperature, wind speed, wind direction) at 5 to 260 ft
  - derived summary: inversion °F, speed and direction shear
  - sun elevation, cloud %, rain rate in/hr, gusts
  - drift vector: downwind bearing and a strength from 0 to 1
- Assessment: status, top reason, recommended droplet class.
- Status: the GO/CAUTION/STOP colors.
- site.ts: farm, blocks, tower, default block.

If a field is missing, for example a spraying flag or a camera-command type, ask the coordinator. Don't add it yourself.

   5. Inversion lid at the lid height with an amber edge. It pulses when the status is STOP.
   6. Wind arrows at the tower for every layer: bold at 5 and 30 ft, faint for the rest.

      - GO: rise and fade
      - high wind: long downwind stream

## Tests (tests/scene.test.ts)
- 30 ft maps to 300 ft of scene elevation (10x), in the unit the helper returns.
- A wind from the north (0 degrees) gives a southward velocity. Also check east and west, so the sign convention is right.
- Lid height is the warmest layer at or below 100 ft, and none when not inverted.
- Under an inversion the drift ceiling is below the lid. In GO conditions it has no ceiling.
- Every tree position falls inside its block. The total stays at or under 30,000, even for a giant test polygon.
- One advection step moves a particle by velocity times dt and wraps it inside the box.

## Performance checklist
- Total particles about 6,000 (wind trails plus drift plus rain). Trees are one instanced layer of at most 30,000.
- Make tree positions once per site, never per frame. Their layer data never changes.
- Particles live in preallocated typed arrays updated in place. Don't create arrays per tick.
- Update triggers go only on layers that changed. The slabs, arrows and lid change on frame or ease ticks, not every particle tick.
- Cap updates at 30 a second. Pause the loop when the tab is hidden.
- Keep the trail length short (about 4 to 6 points).
- Check the frame rate on the production URL in Chrome at 6 sim-hours per second. If it stutters, cut trees to every other row and particles to 4,000 before cutting features.
- Load MapLibre and deck through the dynamic import only, so the server build never touches window.
